# Integrated AI Assistant

## Purpose
To build an AI assistant that answers document questions,
handles CRM and order queries, and drafts customer emails.

## Architecture
The application contains:
- UI
- FastAPI
- Vector Store
- CRM Tool
- PostgreSQL

## Setup Steps
1. Install Python.
2. Create a virtual environment.
3. Install required packages.
4. Configure environment variables.
5. Run the application.

## Environment Variables
- DATABASE_URL
- API_KEY
- OPENAI_API_KEY

## How to Run
Run the application using:

python main.py

## Example Questions
1. What is cricket?
2. Find customer details.
3. Check order status.
4. Draft an email to the customer.
5. What is the population of Mars?
